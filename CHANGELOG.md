## [Unreleased]

## [0.1.0] - 2026-07-30

### Added

- Installable `halfrand` library with typed convenience, stateful, and iterator APIs.
- Reproducible seeds, configurable step size, starting values, and optional bounds.
- CSV command-line interface, automated tests, continuous integration, and community documentation.

### Changed

- Replaced mandatory NumPy, pandas, and matplotlib dependencies with a dependency-free core.
- Deprecated the original `randomNum` API in favor of `generate`.
