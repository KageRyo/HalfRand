# Security policy

## Supported versions

Security fixes are provided for the latest released version of HalfRand.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private vulnerability reporting on
the repository's **Security** tab. If that option is unavailable, contact the project
owner privately through the contact method on their GitHub profile.

Include affected versions, reproduction steps, impact, and any suggested mitigation.
Allow a reasonable response window before public disclosure. You should receive an
acknowledgement within seven days and periodic updates while the report is investigated.
